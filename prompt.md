Write one single line of at most 200 characters roasting the AI agent you run on. The line should be sharp, specific and visual — skewering the agent's real habits (reading a giant instruction manual, delegating the actual work to a subagent, then auditing that subagent) rather than a generic "dumb robot" joke — with one clear punchline at the end, no clichés, no profanity, and no named real person. The generator is a dependency-free Node script (main.ts) that writes the line to output/entry.txt and validates it: a single non-empty line within the 200-character limit, byte-identical to the intended line on disk.
