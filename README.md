# The Long Roast

> "My agent read 4,000 words of instructions, delegated the roast to a subagent, then spent six hours auditing it — and billed it all as 'efficiency'."

A single-line roast of the AI agent this entry runs on — an agent that turns a one-sentence job into a three-department process and invoices it as efficiency.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

This writes the entry to `output/entry.txt` and validates it: a single line, at most 200 characters, byte-identical to the intended line.
